เรื่อง: การวัดหาค่าความต้านทานด้วยวงจรบริดจ์ของวีตสโตน
(Wheatstone Bridge Circuit)

จุดประสงค์การทดลอง

  • เพื่อศึกษาหลักการทำงานของวงจรบริดจ์ของวีตสโตน (Wheatstone Bridge)
  • เพื่อฝึกทักษะการปรับสมดุลของวงจรบริดจ์โดยวัดกระแสไฟฟ้าในแกลแวนอมิเตอร์ จนเป็นศูนย์
  • เพื่อหาค่าความต้านทานที่ไม่ทราบค่า (Rx) จากเงื่อนไขสมดุลของวงจรบริดจ์

ทฤษฎี (Theory)

วงจรบริดจ์ของวีตสโตนประกอบด้วยตัวต้านทาน 4 ตัว (R1, R2, R3 และ Rx) ต่อกันเป็นรูปสี่เหลี่ยมขนมเปียกปูน โดยมีแหล่งจ่ายไฟ DC (V) ต่อเข้าที่โหนด A และ C และมีแกลแวนอมิเตอร์ (Galvanometer) ต่ออยู่ตรงกลางระหว่างโหนด B และ D เพื่อตรวจวัดกระแสไฟฟ้า (Ig)

ภาวะสมดุลของวงจรบริดจ์ (Balanced Bridge Condition):

เมื่อทำการปรับค่าความต้านทาน R3 จนกระทั่งศักย์ไฟฟ้าที่โหนด B และ D เท่ากัน (VB = VD) จะทำให้ไม่มีกระแสไฟฟ้าไหลผ่านแกลแวนอมิเตอร์ นั่นคือ:

Ig = 0

เมื่อวงจรอยู่ในภาวะสมดุล จะได้ความสัมพันธ์ของอัตราส่วนความต้านทาน ตามสมการ:

R1 / R2 = R3 / Rx

ดังนั้น สามารถคำนวณหาค่าความต้านทานที่ไม่ทราบค่า (Rx) ได้จากสมการ:

Rx = (R2 × R3) / R1

วิธีการทดลอง

  1. เริ่มต้นการทดลอง: กดปุ่ม "สุ่มค่า Rx ใหม่" เพื่อให้ระบบสุ่มค่าความต้านทานที่ไม่ทราบค่า
  2. ตั้งค่า R1 และ R2: ปรับค่าความต้านทาน R1 และ R2 บนแถบสไลเดอร์ตามความเหมาะสม
  3. ปรับสมดุลวงจร (R3):
    • ปรับสไลเดอร์ R3 หรือใช้ปุ่มละเอียด (+1, -1, +10, -10) จนกระทั่งเข็มของแกลแวนอมิเตอร์ชี้ที่เลข 0
    • หรือกดปุ่ม "ปรับสมดุลอัตโนมัติ" เพื่อหาจุดสมดุลทันที
  4. คำนวณค่า Rx: นำค่า R1, R2 และ R3 ที่ได้ในภาวะสมดุลไปคำนวณหาค่า Rx ตามสูตร
  5. บันทึกผล: กดปุ่ม "บันทึกผลลงตาราง" เพื่อจัดเก็บข้อมูลลงในตารางบันทึกผล
  6. ทำซ้ำ: กดปุ่ม "สุ่มค่า Rx ใหม่" หรือเปลี่ยนอัตราส่วน R1/R2 แล้วทำการทดลองซ้ำเพื่อเปรียบเทียบผล
