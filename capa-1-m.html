ใบงานการทดลอง: การวัดค่าความจุของตัวเก็บประจุด้วยดิจิทัลมัลติมิเตอร์

ห้องปฏิบัติการเสมือน (Virtual Laboratory - Capacitance Measurement)

1. อุปกรณ์การทดลอง

  • เครื่องดิจิทัลมัลติมิเตอร์ สำหรับวัดค่าความจุไฟฟ้า
  • ตัวเก็บประจุ ขนาด C = 100.0 nF จำนวน 10 ตัว

2. ทฤษฎี (Theory)

ตัวเก็บประจุ (Capacitor) เป็นอุปกรณ์อิเล็กทรอนิกส์ที่ทำหน้าที่เก็บสะสมประจุไฟฟ้า โดยมีหน่วยวัดความจุเป็น ฟารัด (Farad, F) เมื่อนำตัวเก็บประจุที่มีค่าความจุเท่ากัน C จำนวน N ตัว มาต่อร่วมกันในวงจร จะได้ค่าความจุรวม (Ctotal) ดังนี้:

  • การต่อแบบอนุกรม (Series Connection): การต่อตัวเก็บประจุแบบเรียงต่อกัน จะทำให้ระยะห่างระหว่างแผ่นเพลทเสมือนเพิ่มขึ้น ส่งผลให้ความจุรวมของวงจรลดลง คำนวณได้จากสูตร:
    1 / Ctotal = (1/C₁) + (1/C₂) + ... + (1/CN)  →  กรณี C เท่ากันทุกตัว: Ctotal = C / N
  • การต่อแบบขนาน (Parallel Connection): การต่อตัวเก็บประจุแบบขนานกัน จะเป็นการเพิ่มพื้นที่หน้าตัดของแผ่นเพลทรับประจุ ทำให้ความจุรวมของวงจรเพิ่มขึ้น คำนวณได้จากสูตร:
    Ctotal = C₁ + C₂ + ... + CN  →  กรณี C เท่ากันทุกตัว: Ctotal = N × C

3. วิธีการทดลอง

ตอนที่ 1: การวัดค่าความจุรวมของตัวเก็บประจุแบบอนุกรม (Series Connection)

  1. เปิดโปรแกรมจำลองการทดลอง และสังเกตการตั้งค่าเริ่มต้น
  2. คลิกเลือกรูปแบบการต่อเป็น "ต่ออนุกรม (Series)" ที่แผงควบคุม
  3. เลื่อนสไลเดอร์ "จำนวนตัวเก็บประจุ (N)" ไปที่ 1 ตัว
  4. อ่านค่าความจุรวมทางทฤษฎี (Ccalc) และค่าความจุที่วัดได้จริงจากหน้าจอดิจิทัลมัลติมิเตอร์
  5. กดปุ่ม "บันทึกผลลงตาราง" เพื่อบันทึกค่าการทดลอง
  6. ปรับเพิ่มจำนวนตัวเก็บประจุ N เป็น 2, 4, และ 10 ตัว ตามลำดับ โดยสังเกตการเปลี่ยนแปลงของการต่อสาย/ภาพจำลองแผ่นเพลท และบันทึกผลการวัดลงในตารางทุกครั้ง

ตอนที่ 2: การวัดค่าความจุรวมของตัวเก็บประจุแบบขนาน (Parallel Connection)

  1. คลิกเปลี่ยนรูปแบบการต่อเป็น "ต่อขนาน (Parallel)" ที่แผงควบคุม
  2. เลื่อนสไลเดอร์ "จำนวนตัวเก็บประจุ (N)" ไปที่ 1 ตัว
  3. อ่านค่าที่วัดได้จากดิจิทัลมัลติมิเตอร์ และกดปุ่ม "บันทึกผลลงตาราง"
  4. ปรับเพิ่มจำนวนตัวเก็บประจุ N เป็น 2, 5, และ 10 ตัว ตามลำดับ สังเกตลักษณะการต่อขนานวงจรบนหน้าจอเสมือน และบันทึกผลลงในตารางทดลอง

4. โปรแกรมจำลองการทดลอง (Virtual Lab Simulator)

ต่ออนุกรม (Series)
ต่อขนาน (Parallel)
สถานะการวัดปัจจุบัน:
• ชนิดการต่อ: ต่ออนุกรม
• จำนวนตัวเก็บประจุ (N): 1 ตัว
• ความจุคำนวณทางทฤษฎี (Ccalc): 100.0 nF
• ค่าที่วัดได้จากมัลติมิเตอร์: 100.0 nF

5. ตารางบันทึกผลการทดลอง

ครั้งที่ รูปแบบการต่อ จำนวนตัวเก็บประจุ N (ตัว) ความจุแต่ละตัว C (nF) ความจุคำนวณทางทฤษฎี (nF) ค่าที่วัดได้จากมัลติมิเตอร์
